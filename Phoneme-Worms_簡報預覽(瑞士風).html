MODULE DETAIL 01
自訂測驗工作坊 & 單字卡英雄展示
全新題型出題引擎：徹底解決「自訂詞彙」標籤誤植，實現標準化看英選中/看中選英
SMART WORKSHOP
FEATURE SPECIFICATION
精準出題系統重構
1. 雙向自動出題模式
• 看英選中：大字題幹顯示英文單詞（如 workout），四個選項均為純中文釋義。
• 看中選英：大字題幹顯示純中文釋義（如 訓練，鍛鍊），選項均為純英文單詞。

2. 三層干擾項生成器 (Distractor Engine)
• 優先層：抽取自訂測驗清單內其他卡片，混淆度最高。
• 次級層：抽取使用者個人單字本 (Vocab Notebook)。
• 保底層：內建 60+ 高頻常備詞庫，杜絕題庫枯竭產生空白選項。
ENGINEERING HIGHLIGHTS
NLP 雙向智慧分詞與互動
1. smartSplitEnZh 正規化函式
• 採用 Unicode 正則智能辨別英文名詞與中文釋義邊界。
• 完整保留如 workout (尤指體育的) 訓練 中括號說明資訊，不發生文字裁切斷裂。

2. 全流程鍵盤盲打支援
• 題型支援 1 / 2 / 3 / 4 或 A / B / C / D 瞬間作答。
• 快捷播放單字真人發音，答題即時動畫回饋。

3. 自訂卡片多模態圖片更換
• 彈窗提供電腦本地上傳與線上 URL 直連，支援 Esc / 遮罩快速關閉。

DATA FLOW & WORKFLOWS
核心業務數據管線與狀態流轉
以三條高可靠工作流貫穿用戶學習全歷程
PIPELINE DESIGN
WORKFLOW 01
NLP 批量匯入流
1. 多源輸入：文字剪貼簿或 Vision OCR 上傳。
2. 正規化過濾：去除空行與雜訊，執行 smartSplitEnZh 雙向切割。
3. 卡片渲染：生成可選取之預覽網格，支援個別替換配圖。
4. 一鍵沉澱：批量匯入個人生字庫並排除於日課池外。
WORKFLOW 02
每日防重複輪播流
1. 日期哈希種子：依自然日生成不可預測隨機種子。
2. 差集計算：池 = 總題庫 - 個人生字本 - 本週已讀。
3. 多題型同步分發：單字卡、閱讀測驗、克漏字三模組同步換池。
4. 隔日 00:00 自動歸檔：推進下一循環。
WORKFLOW 03
多人對戰狀態機流
1. 創房 / 加入：6 碼房間註冊與雙方角色鎖定。
2. 題目廣播：後端同步下發相同題幹與時限。
3. 傷害結算：作答耗時 + 連擊倍率 + 職業技能乘積。
4. 廣播血量：勝負判定與經驗值回饋獎勵。
